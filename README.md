# LibraHub Library Management Web App

Frontend prototype for GitHub/Render.

## Demo logins
Student: student / 1234
Library: librarian / 1234

## Features
- Student and librarian login
- Book catalog/search
- 14-day issue period
- Return tracking
- Automatic demo overdue fine at ₹5/day
- Payment/fine records
- Librarian add/delete books
- Responsive design

## Run
Open index.html in a browser.

## Deploy
Upload all three files to GitHub and deploy the repository as a static site on Render.

This version is a frontend prototype. Login/payment data is stored only in browser memory and resets on refresh. For a real production system, connect the UI to a backend such as Java Spring Boot + MySQL and use a real payment gateway.
